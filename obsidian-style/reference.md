# Выжимка стайлгайда Obsidian (резерв, если сайт недоступен)

Источник: https://obsidian.md/ru/help/style-guide (снято 2026-10-01). Актуальная версия — на сайте.

## Терминология

- «Сочетание клавиш» (keyboard shortcut), а не hotkey — кроме названия самой функции.
- «Выбрать» (select), а не «нажать/кликнуть»; tap — только для сенсорных действий на мобильных.
- «Заметка» — Markdown-файл; «файл» — другие расширения.
- «Название заметки», а не «заголовок заметки»; «активная заметка», а не «текущая».
- «Папка», а не «директория»; «тип файла», а не «формат файла» (если не о формате данных).
- heading, а не header; sidebar слитно; sync, а не synchronise; search term, а не search query.
- maximum/minimum полностью, не max/min; perform (команду), не invoke/execute.
- Продукты начинаются с Obsidian: Obsidian Sync, Obsidian Publish.

## Язык

- Простые слова, активный залог, явные формулировки, без идиом.
- Английский — американская орфография (organize).

## Регистр

- Регистр предложения: «Как Obsidian хранит данные», не «Как Obsidian Хранит Данные».
- Элементы интерфейса — в точности как в приложении.

## Интерфейс

- Текст кнопок — **жирным**.
- Путь по интерфейсу — через → : **Настройки → Плагины сообщества**.
- «Нижний левый угол» (прил.), «внизу слева» (сущ.); для настроек направление не указывать.
- Вертикально — «над» / «под».
- «Открыть» заметку (целевая скрыта), «переключиться» (обе открыты).

## Клавиши

- Одиночная клавиша с символом: «клавиша дефис (-)».
- Сочетания без пробелов: `Ctrl+Z` (Windows), `Command+Z` (macOS); не `Ctrl + Z`, не `Ctrl/Cmd+Z`.
- Одинаковое на всех платформах — без ОС: `Escape`.

## Markdown

- Пустые строки между блоками.
- Длинное тире после жирного термина: **Меню видов** — создание и переключение видов.
- Реалистичные примеры (`task:(call OR schedule)`), не foo/bar.
- Повелительное наклонение в заголовках и шагах: «Настройте», не «Настройка».
- Список — для независимых пунктов, требований, параметров, шагов; текст — для объяснений и связанных процессов.
- Таблицы — только для сравнений, не для простых списков.
- Платформы: подразделы «### Компьютер» и «### Мобильные устройства» только при существенных различиях.

## Выносные блоки

| Тип | Синтаксис | По умолчанию |
|-----|-----------|--------------|
| Подсказка | `> [!tip]-` | Свёрнут |
| Информация | `> [!info]+` | Развёрнут |
| Предупреждение (потеря данных) | `> [!warning]+` | Никогда не свёрнут |
| Пример | `> [!example]-` | Свёрнут |

## Ссылки

- Wiki-ссылки `[[Название заметки#Раздел|описательный текст]]`, один раз на термин на странице, только если страница даёт значимый контекст.

## Изображения и значки

- .png или .svg, 1920 x 1080 пикселей, сжатие 65–75 %, только когда словами объяснить трудно.
- Якоря: `#icon`, `#interface`, `#outline`.
- Значки: Lucide (`lucide-`) или Obsidian (`obsidian-icon-`), SVG 18x18, обводка 1.5, в `Attachments/icons`, вставка `![[lucide-cog.svg#icon]]`.

## Метаданные и переводы

- Свойство `description` — до 150 символов, объективное резюме страницы.
- Переводить всё: названия заметок, папок, псевдонимы, вложения, текст ссылок; проверять битые ссылки.
