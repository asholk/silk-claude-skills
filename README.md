# silk-claude-skills

Глобальные скилы Claude Code (`~/.claude/skills`).

| Скил | Что делает |
|---|---|
| `concept` | Концепт: два исследователя (Claude + Codex), три предложения и мини-сайт с лендингами |
| `dorabotay` | Быстрая доработка: код пишет субагент, главный процесс делает ревью |
| `obsidian-style` | Применяет стайлгайд Obsidian к текстам, плагинам и документации |
| `predlozhi` | Предложения по улучшению кода от Claude и Codex — одна таблица без правок |
| `razrabotay` | Разработка с поиском лучших практик, планом и проверкой |
| `staged-development` | Поэтапная разработка: план, параллельные субагенты, мониторинг, ревью, коммиты |

## Установка

```bash
git clone https://github.com/asholk/silk-claude-skills.git ~/.claude/skills
```
